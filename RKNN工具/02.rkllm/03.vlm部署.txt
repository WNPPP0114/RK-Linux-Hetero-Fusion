二、模型导出（export）

Qwen3-VL-2B 模型导出操作指南
确保所有操作都在 multimodal_model_demo 根目录下执行。

1. 导出 Vision 部分 (ONNX)
将 PyTorch 视觉编码器导出为 ONNX 格式。
输入：Qwen3-VL-2B-Instruct (HuggingFace 模型文件夹)
输出：qwen3-vl_vision.onnx

python export/export_vision.py --path Qwen3-VL-2B-Instruct --model_name qwen3-vl --height 224 --width 224
python export/export_vision.py --path Qwen3-VL-4B-Instruct --model_name qwen3-vl --height 224 --width 224

2. 转换 Vision 部分 (RKNN)
将 ONNX 模型转换为 RKNN 模型（用于 NPU 推理）。
输入：qwen3-vl_vision.onnx
输出：qwen3-vl_vision_rk3588.rknn

python export/export_vision_rknn.py --path export/onnx/qwen3-vl_vision.onnx --model_name qwen3-vl --height 224 --width 224
python export/export_vision_rknn.py --path export/onnx/qwen3-vl_vision.onnx --model_name qwen3-vl --height 224 --width 224

3. 生成 LLM 量化校准数据
提取文本和图像特征的 Embeddings 用于 LLM 量化。
输入：datasets.json (及对应图片), Qwen3-VL-2B-Instruct
输出：inputs.json, data/inputs_embeds/*.npy

python data/make_input_embeds_for_quantize.py --path Qwen3-VL-2B-Instruct
python data/make_input_embeds_for_quantize.py --path Qwen3-VL-4B-Instruct

4. 导出 LLM 部分 (RKLLM)
将 LLM 模型量化并导出为 RKLLM 格式。
输入：Qwen3-VL-2B-Instruct, 校准数据
输出：qwen3-vl-2b-instruct_w8a8_rk3588.rkllm

python export/export_rkllm.py \
  --path Qwen3-VL-2B-Instruct \
  --target-platform rk3588 \
  --num_npu_core 3 \
  --quantized_dtype w8a8 \
  --device cpu

python export/export_rkllm.py \
  --path Qwen3-VL-4B-Instruct \
  --target-platform rk3588 \
  --num_npu_core 3 \
  --quantized_dtype w8a8 \
  --device cpu

最终产物：

qwen3-vl_vision_rk3588.rknn
qwen3-vl-2b-instruct_w8a8_rk3588.rkllm


当前 export 目录结构如下：
export/
├── export_rkllm.py          # LLM 导出脚本
├── export_vision.py         # Vision ONNX 导出脚本
├── export_vision_qwen2.py   # (旧/备用) Qwen2 Vision 导出脚本
├── export_vision_rknn.py    # Vision RKNN 转换脚本

    └── qwen3-vl-2b-instruct_w8a8_rk3588.rkllm

**执行推理**
开发板推理指令
先激活环境
conda activate rknn

请在开发板上，进入包含所有上传文件的目录（例如 /home/topeet/RKLLM/qwen3-vl-2b）后，执行以下命令。

增加文件句柄限制 (每次登录终端都需要)
ulimit -HSn 102400

设置动态库路径 (每次登录终端都需要)
export LD_LIBRARY_PATH=./li

执行推理
根据 main.cpp 的要求，正确的指令格式如下：
./demo <图片路径> <Vision模型> <LLM模型> <最大生成长度> <最大上下文长度> <NPU核心数>
